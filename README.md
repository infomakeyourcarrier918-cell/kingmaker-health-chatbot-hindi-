# 🩺 Kingmaker Health Chatbot (Multi-Language Demo)

This is a simple **multi-language health chatbot** built with Streamlit.  
It supports both **English** and **Hindi** users.

## Features
- 👦 Youth: Diet & fitness tips  
- 👩 Women: Menstrual cycle health & awareness  
- 🩺 Diabetes Patients: Food awareness & lifestyle tips  
- 🌐 Multi-language support (English / Hindi)

## 🚀 Run locally
```bash
streamlit run health_chatbot.py
